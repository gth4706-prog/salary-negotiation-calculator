🤖 안드로이드

  1. 크롬으로 joeltool.com/eggwar 를 엽니다
  2. 주소창 오른쪽 ⋮ 를 누릅니다
  3. 앱 설치 또는 홈 화면에 추가 를 누릅니다
  4. 홈 화면에 생긴 Egg War 아이콘으로 엽니다

설치하면 주소창이 사라지고 전체화면으로 열립니다. 뒤로가기 버튼도 게임 안에서 동작합니다.

🍎 아이폰 · 아이패드

  1. 사파리로 joeltool.com/eggwar 를 엽니다
  2. 아래쪽 공유 버튼(⬆︎)을 누릅니다
  3. 목록을 내려 홈 화면에 추가 를 누릅니다
  4. 오른쪽 위 추가 를 누릅니다
  5. 홈 화면에 생긴 Egg War 아이콘으로 엽니다

아이폰 사파리에는 전체화면 버튼이 없습니다. 홈 화면에 추가하는 것이 주소창을 없애는 유일한 방법입니다.

가로로 눕히면 전장이 넓어집니다. 아이폰은 웹에서 화면 방향을 고정할 수 없어, 회전 잠금이 켜져 있으면 풀어야 합니다.

스토어에서는 못 받나요?

아직 없습니다. Egg War 는 설치 파일(APK·IPA)이 없는 웹게임입니다. 위 방법으로 홈 화면에 추가하면 스토어 앱과 거의 같게 동작합니다 — 아이콘·전체화면·오프라인 실행까지.

플레이스토어·앱스토어 등록은 사람이 모인 뒤에 판단할 일로 남겨 두었습니다.
