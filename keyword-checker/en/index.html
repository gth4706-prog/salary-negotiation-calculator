How does keyword checking work

How keywords are extracted

Once you enter a URL, we fetch that page and read the title, H1, subheadings, meta description, and body copy separately, weighting each location differently to rank which words are actually emphasized. A word in the title counts 5x more than the same word appearing only in the body. We only strip grammatical particles when the bare form also appears standalone elsewhere in the document, so genuine multi-word terms don't get split apart.

How to use the results

If the top-ranked word doesn't match the search term you were targeting, that means the page is reading as a different topic than you intended. Fix the title and subheadings first — editing only the body copy has the weakest effect.

What this doesn't do

This tool can't tell you search volume or competition level. It only shows what words your page is actually read as being about. It can't read content rendered later by JavaScript, and it doesn't work on pages that require login.
