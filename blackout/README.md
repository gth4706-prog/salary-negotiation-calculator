# 블랙아웃 — 어둠 속 야광 페인트건 실시간 대전

> 현재 규칙·구현·검증·배포 상태는 **[HANDOVER.md](HANDOVER.md)** 가 정본이다.
> 이 문서는 설계 배경과 「에그워에서 무엇을 가져오고 무엇을 안 가져왔나」만 적는다.

불 꺼진 8×8 방. 보이는 건 **내가 바라보는 쪽 앞 두 칸뿐.** 가구도 상대도 그 안에 들어와야
보인다. 페인트는 야광이라 어둠 속에 영원히 남고, 젖은 신발은 **걸음마다 방향이 있는 발자국**을 찍는다.
까맣던 방을 페인트로 긁어내며 상대를 찾는다. **실시간 대전이지만 턴제**다.

설치·가입 없음. 빌드 도구 없음. `index.html` 을 브라우저로 열면 그대로 돈다.

## 구조

```
blackout/
├── index.html       화면 골격(메뉴·규칙·로비·방·대전·결과)
├── css/style.css    레이아웃 · 조작부. 캔버스를 안 쓴다 — DOM 격자.
├── css/rooms.css    칸의 층(그림·안개·빛·야광 얼룩·사람) · 벽 테두리 · 타격 연출
└── js/
    ├── svgart.js    내장 그림 — 가구·마루·전등·얼룩을 컨셉 팔레트로 그린 SVG
    ├── rooms.js     방 정답지(8×8 세 종). 화면과 봇은 이걸 직접 못 본다.
    ├── core.js      규칙 엔진. DOM·네트워크·Math.random 을 안 쓴다(결정론).
    ├── net.js       방 접속(WebSocket) + P2P 직결(WebRTC). 에그워에서 이식.
    ├── match.js     턴 진행 · 행동 즉시 전송 · 상태 해시 대조 · 재접속 복구
    ├── bot.js       연습 상대. **아는 것만** 보고 추리한다(상태를 훔쳐보지 않는다).
    ├── art.js       내장 SVG 를 깔고, 그림 파일이 있으면 칸 단위로 잘라 덮는다
    ├── tutorial.js  8단계 안내판
    ├── ui.js        화면. `Core.view()` 가 내준 것만 그린다.
    ├── sfx.js       WebAudio 소리(오디오 파일 없음)
    └── main.js      화면 전환 · 로비 · 연결 배선
```

검증은 `tests/README.md` 참고.

## 에그워에서 가져온 것 / 안 가져온 것

**가져온 것** (전부 사람이 신고해서 알게 된 것들)

- 백그라운드 전환은 퇴장이 아니다. `pagehide` 에서 방을 나가면 폰 화면이 꺼지는
  순간 스스로 방을 나간다.
- 끊김에는 두 종류가 있다 — 다시 붙는 중(`drop`)과 정말 끝(`close`). 구분 안 하면
  깜빡임 한 번이 판을 끝낸다.
- 한국 ISP 는 Cloudflare 무료 트래픽을 해외로 우회시킨다(왕복 ~500ms).
  그래서 **P2P 직결을 먼저** 시도한다.
- TURN 자격증명을 클라이언트에 박지 않는다. 서버 `/ice` 가 단기 발급한다.
- 빈 방이 기본 상태다. 정직하게 말하고, 나갈 길을 주고, 혼자서도 놀 수 있게 한다.

**일부러 안 가져온 것**

- **록스텝.** 실시간이 아니라 턴제라 필요 없다. 턴 하나 = 메시지 하나(+행동마다 미리 한 번).
- **캔버스 전체화면.** 기종마다 레터박스가 어긋나 결국 「가로로 돌려주세요」까지
  세워야 했다. DOM 격자는 세로 화면에서 그냥 맞는다(`tests/layout.js` 가 7기종 확인).
- **오디오 파일.** 6MB mp3 대신 WebAudio 로 만든다.
- **거대 파일.** 에그워 `combat.js` 는 324KB 였다. 여기서는 제일 큰 파일이 25KB 안팎이다.

## 규칙에 대해 — 어떻게 지금 모양이 됐나

처음 규칙(10×10, 아무 단서 없음) 그대로 봇끼리 2,000판을 돌려 보니 **한 판도 끝나지
않았다.** 전등 버튼이 그걸 풀었다. 실서버에서 두 판을 둔 설계자는 「맞았는지 모르겠고,
맵이 커서 못 찾겠다」고 했고, 그래서 v0.5 가 됐다: 8×8, 바라보는 쪽만 보이는 시야각,
미리 안 보이는 가구, 영구 야광 페인트, 맞으면 보이는 윤곽, 네 겹 타격 연출.

설계에 없던 규칙을 넣었다 뺀 일이 두 번 있다(총성·충돌). 지금 설계에 없는 규칙은
인기척(바로 옆 한 칸) 하나뿐이고, 그건 설계자가 확정했다.

봇끼리 800판 실측 (`node blackout/tests/balance.js 800`, v1.0 — 두 칸 시야 · 방향이 있는 발자국):

| | |
|---|---|
| 격추로 끝난 판 | **93%** |
| 무승부 | 4.3% |
| 선공 승률 | 53% |
| 평균 턴수 | 21.5턴 |
| 명중률 | 40% |
| 판당 발자국 | 5.03개 (v0.9 는 0.25개였다 — 규칙이 죽어 있었다) |

근거와 눈금은 `js/core.js` 의 규칙 상수 주석에 전부 적혀 있다.
