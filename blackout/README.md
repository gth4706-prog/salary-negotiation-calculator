# 블랙아웃 — 어둠 속 페인트건 실시간 대전

불 꺼진 10×10 방. 서로의 모습은 **절대** 보이지 않는다.
바닥의 페인트 얼룩, 발자국, 총성만으로 상대 위치를 추리해 페인트건을 맞힌다.
**실시간 대전이지만 턴제**다.

설치·가입 없음. 빌드 도구 없음. `index.html` 을 브라우저로 열면 그대로 돈다.

## 구조

```
blackout/
├── index.html       화면 골격(메뉴·규칙·로비·방·대전·결과)
├── css/style.css    어둠 테마. 캔버스를 안 쓴다 — DOM 격자.
└── js/
    ├── core.js      규칙 엔진. DOM·네트워크·Math.random 을 안 쓴다(결정론).
    ├── net.js       방 접속(WebSocket) + P2P 직결(WebRTC). 에그워에서 이식.
    ├── match.js     턴 진행 · 상태 해시 대조 · 재접속 복구
    ├── bot.js       연습 상대. **공개 정보만** 보고 추리한다(상태를 훔쳐보지 않는다).
    ├── ui.js        화면. `Core.view()` 가 내준 것만 그린다.
    ├── sfx.js       WebAudio 소리(오디오 파일 없음)
    └── main.js      화면 전환 · 로비 · 연결 배선
```

검증은 `tests/README.md` 참고.

## 에그워에서 가져온 것 / 안 가져온 것

**가져온 것** (전부 사람이 신고해서 알게 된 것들)

- 백그라운드 전환은 퇴장이 아니다. `pagehide` 에서 방을 나가면 폰 화면이 꺼지는
  순간 스스로 방을 나간다.
- 끊김에는 두 종류가 있다 — 다시 붙는 중(`drop`)과 정말 끝(`close`). 구분 안 하면
  깜빡임 한 번이 판을 끝낸다.
- 한국 ISP 는 Cloudflare 무료 트래픽을 해외로 우회시킨다(왕복 ~500ms).
  그래서 **P2P 직결을 먼저** 시도한다.
- TURN 자격증명을 클라이언트에 박지 않는다. 서버 `/ice` 가 단기 발급한다.
- 빈 방이 기본 상태다. 정직하게 말하고, 나갈 길을 주고, 혼자서도 놀 수 있게 한다.

**일부러 안 가져온 것**

- **록스텝.** 실시간이 아니라 턴제라 필요 없다. 턴 하나 = 메시지 하나.
  에그워를 제일 오래 태운 「입력 지연 몇 프레임」 논쟁이 아예 안 생긴다.
- **캔버스 전체화면.** 기종마다 레터박스가 어긋나 결국 「가로로 돌려주세요」까지
  세워야 했다. DOM 격자는 세로 화면에서 그냥 맞는다(`tests/layout.js` 가 6기종 확인).
- **오디오 파일.** 6MB mp3 대신 WebAudio 로 만든다.
- **거대 파일.** 에그워 `combat.js` 는 324KB 였다. 여기서는 제일 큰 파일이 25KB다.

## 규칙에 대해 — 처음 설계와 달라진 곳

처음 규칙 그대로 봇끼리 2,000판을 돌려 보니 **한 판도 끝나지 않았다**
(격추 0% · 무승부 76% · 이동 0회 · 발자국 0회). 어디든 쏠 수 있으면 움직일 이유가
없어서 둘 다 제자리에 붙박이고, 그러면 페인트를 밟을 일이 없어 발자국 규칙이
한 번도 발동하지 않는다.

한때 **총성**(쏘면 쏜 자리가 상대 화면에 뜬다)을 넣어 숫자를 맞췄다가 **뺐다.**
설계에 없던 규칙이었다 — 어둠 속에서 쏘는 사람의 위치가 보일 이유가 없다.
그 자리를 대신하는 것이 **전등 버튼**이다. 단서를 「공짜로 새어 나오는 정보」가
아니라 「가서 얻어 오는 것」으로 만든다. 그러자 다들 버튼 쪽으로 움직이고,
움직이니 페인트를 밟고, 그래서 발자국이 남는다 — 설계한 고리가 그대로 돈다.

처음 설계에 없는 규칙은 이제 **인기척 하나**뿐이다(바로 옆 한 칸).

봇끼리 3,000판 실측 (`node blackout/tests/balance.js 3000`):

| | |
|---|---|
| 격추로 끝난 판 | **99.5%** |
| 무승부 | 0.4% |
| 선공 승률 | 48.9% (공정) |
| 평균 턴수 | 35턴 |
| 명중률 | 21.7% |
| 판당 피해 | 8.17 / 10 |
| 판당 전등 켜기 | 3.07회 |
| 판당 페인트 밟기 · 발자국 · 충돌 | 1.85 · 0.21 · 0.60회 |

근거와 눈금은 `js/core.js` 의 규칙 상수 주석에 전부 적혀 있다.
