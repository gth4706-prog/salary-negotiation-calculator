# 블랙아웃 그림 명세

이 폴더에 파일을 넣고 **`node blackout/tests/assets-manifest.js`** 를 한 번 돌리면
게임이 찾아 쓴다(`js/art.js` 가 `manifest.json` 만 믿는다). 목록을 안 만들어도
파일을 하나하나 더듬어 쓰긴 하지만, 그러면 접속마다 404 가 쌓이니 돌려 두는 게 좋다.
없는 파일은 CSS 로 그린 시험 자산으로 대신 보인다. 반만 있어도 깨지지 않는다.

기준 그림: `concept/concept-01.jpg` — **이 느낌이 정답이다.**
위에서 내려다본 어두운 방, 따뜻한 스탠드 불빛, 물총 든 아이, 분홍/청록 페인트.
픽사풍 3D 렌더 느낌, 채도는 페인트에만.

## 지켜야 할 것

- **전부 합쳐 2MB 안.** 에그워는 그림 한 장이 5MB 였고 그게 첫 로딩을 죽였다.
  PNG 는 `pngquant`/`oxipng`, 바닥은 JPG 도 된다(투명 필요 없음).
- 시점은 **정확히 위에서 아래(orthographic top-down)**. 벽에 높이가 보이면 안 된다 —
  격자와 어긋난다. `concept-01.jpg` 의 방은 살짝 기울어져 있는데 그건 분위기 참고용이다.
- **가구 자리는 그림이 아니라 데이터가 정한다** (`js/rooms.js`). 그림은 거기에 맞춰
  얹힌다. 방 바닥 그림에 가구를 **그리지 말 것** — 가구는 따로 조각으로 만든다.
- 두 플레이어 색: **청록 `#3de1d0`(나) · 분홍 `#ff4d8d`(상대)**. 이 둘 외의 채도 높은
  색은 쓰지 않는다. 어둠 속에서 «색 = 정보»다.
- 스타일은 한 사람이 그린 것처럼 통일. 조명 방향도 통일(위에서 약간 왼쪽).

## 아직 그림이 없는 것 중 효과가 큰 순서

1. **얼룩 4장** — 화면의 90% 를 차지하는 시각 언어. 이것만 바꿔도 인상이 달라진다.
2. **두 방 바닥** — 「진짜 방」이 된다.
3. **가구 10장**
4. **전등 2장**
5. 메뉴 배경 한 장(선택) — `concept-01.jpg` 사무실 장면을 그대로 써도 된다.

## 소리 (`js/sfx.js`)

지금은 WebAudio 로 만든 삐 소리. 파일로 바꾸려면 `BANK` 의 함수를 `new Audio()` 로.
발사·피격·발소리·전등 딸깍·물방울 앰비언트. **한 파일 100KB 이하**, OGG 또는 MP3.
