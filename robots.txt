#   읽지 못하게 만들어서, 색인에서 빠지는 걸 **막는다.**
#
# 그래서 크롤링은 허용하고, 색인 제외는 각 페이지의 noindex 메타로 처리한다.

#   /eggwar/            전체화면 게임 캔버스 — 크롤러가 읽을 본문이 거의 없음
#   /arena/             위와 동일(구 버전 경로)
#   /youtube-transcript/ 유튜브가 데이터센터 요청을 차단해 기능 정지 상태
#   /anon-letter/, /my-branch/  D1 미생성으로 백엔드 없음
#
# ⚠️ /eggwar/index.html 의 noindex 메타는 게임을 작업하는 다른 세션이 그 파일을
