# 블랙아웃 그림 명세

**지금 들어 있는 그림은 전부 컨셉아트에서 오려 만든 것이다** — `tests/concept-crops.py` 가
`concept/office.jpg` 와 `concept/concept-01.jpg` 에서 가구·마루·얼룩을 잘라 칸 규격에 맞춘다
(가장자리를 부드럽게, 마루는 맨 바닥 조각을 거울 타일로 깔고 방마다 조명을 굽는다).
좌표를 바꾸거나 새 조각을 더하려면 그 파일을 고치고 다시 돌린다. 그림 생성 도구는 쓰지 않았다.

이 폴더에 파일을 넣고 **`node blackout/tests/assets-manifest.js`** 를 한 번 돌리면
게임이 찾아 쓴다(`js/art.js` 가 `manifest.json` 만 믿는다). 목록을 안 만들어도
파일을 하나하나 더듬어 쓰긴 하지만, 그러면 접속마다 404 가 쌓이니 돌려 두는 게 좋다.
없는 파일은 **내장 SVG 그림**(`js/svgart.js`, 컨셉 팔레트로 그린 가구·마루·전등·얼룩)으로
보인다. 반만 있어도 깨지지 않는다. 내장 그림보다 나을 때만 파일로 바꾸면 된다.

기준 그림: `concept/concept-01.jpg` — **이 느낌이 정답이다.**
위에서 내려다본 어두운 방, 따뜻한 스탠드 불빛, 물총 든 아이, 분홍/청록 페인트.
픽사풍 3D 렌더 느낌, 채도는 페인트에만.

**v0.5 부터 그림은 칸 단위로 잘라 쓴다** (`js/art.js` 의 `slice`). 가구는 시야에 든 칸만
보이고, 야광 얼룩은 그 칸의 조각을 얼룩 모양으로 뚫어 보여 준다(스크래치 아트). 그래서
「책상 3칸 그림 한 장」을 넣으면 게임이 알아서 세 조각으로 나눠 쓴다. 방은 **8×8** 이다.

## 지켜야 할 것

- **전부 합쳐 2MB 안.** 에그워는 그림 한 장이 5MB 였고 그게 첫 로딩을 죽였다.
  PNG 는 `pngquant`/`oxipng`, 바닥은 JPG 도 된다(투명 필요 없음).
- 시점은 **정확히 위에서 아래(orthographic top-down)**. 벽에 높이가 보이면 안 된다 —
  격자와 어긋난다. `concept-01.jpg` 의 방은 살짝 기울어져 있는데 그건 분위기 참고용이다.
- **가구 자리는 그림이 아니라 데이터가 정한다** (`js/rooms.js`). 그림은 거기에 맞춰
  얹힌다. 방 바닥 그림에 가구를 **그리지 말 것** — 가구는 따로 조각으로 만든다.
- 두 플레이어 색: **청록 `#3de1d0`(나) · 분홍 `#ff4d8d`(상대)**. 이 둘 외의 채도 높은
  색은 쓰지 않는다. 어둠 속에서 «색 = 정보»다.
- 스타일은 한 사람이 그린 것처럼 통일. 조명 방향도 통일(위에서 약간 왼쪽).

가구 그림 크기는 「칸당 100px」 기준이다. 3×1칸이면 300×100. 여백 없이 꽉 채운다.
게임은 칸마다 `background-size: (가로칸수×100%) (세로칸수×100%)` 로 잘라 붙이므로
**칸 경계에 걸치는 디테일은 잘려 보여도 이상하지 않게** 그린다(가구 전체가 한 번에 보이는
일은 전등을 켰을 때뿐이다).

## 더 올리려면

1. **아이 전신 토큰** — 지금은 컨셉에서 오린 얼굴 원형(`kid-top.png`). 위에서 본 전신(총 든 모습)을
   그리면 한 단계 더. 컨셉 04 패널의 위에서 본 아이(x 950~1050, y 545~640)가 참고.
2. **전등 2장**(`lamp-off/on.png`) — 지금은 내장 SVG.
3. **진짜 소파** — 지금은 침대 발치 벤치로 대신한다.
4. 오린 조각이 흐리면 원본을 더 큰 해상도로 다시 그려 `concept/` 에 넣고 좌표만 맞춘다.

## 소리 (`js/sfx.js`)

지금은 WebAudio 로 만든 삐 소리. 파일로 바꾸려면 `BANK` 의 함수를 `new Audio()` 로.
발사·피격·발소리·전등 딸깍·물방울 앰비언트. **한 파일 100KB 이하**, OGG 또는 MP3.
